# 知识边界 · Knowledge Boundary

> 你的知识，止于何处？
> 用 596 道选择题，横跨 18 大知识领域，探测你知识面的疆域边界。

![领域](https://img.shields.io/badge/领域-18-7dd3fc) ![题目](https://img.shields.io/badge/题目-596-34d399) ![技术](https://img.shields.io/badge/技术-零依赖静态站-8b5cf6)

## 这是什么

一个**知识面覆盖程度测试网页**：从量子力学到世界杯，从《论语》到烘焙发酵，从星座天体到二次元迷因。每道题都是一次对你某一领域**知晓深度**的测量，最终汇成一张属于你的**知识星图**（雷达图）+ 加权正确率。

- **18 大领域，596 道题**（约 26% 易 / 55% 中 / 19% 难），按知识体量赋权
- 单选四选一，**干扰项均为真实易混淆内容**，答对需要真区分力
- **作答即锁定**：选完不能改；答对自动进下一题，答错停留让你看清解析、手动点下一题
- **「我手滑了」×5**：答错可消耗机会改判为「这题我确实会」，全程限 5 次
- **答满 100 题**后，任何时刻都能查看当前结果，看完可继续作答
- **实时保存**：每答一题即写入 localStorage，刷新 / 误关不丢进度，可随时继续
- **难度加权计分**：易×1 / 中×1.5 / 难×2，硬题更能拉开「精通度」
- **结果可视化**：18 轴雷达图 + 领域排名 + 综合等级称号
- **重测薄弱领域**：一键只重做低于 65% 的领域

## 快速开始

纯静态站，零依赖，三种方式任选：

```bash
# 方式一：直接双击打开
start index.html

# 方式二：本地静态服务器
python -m http.server 8000
# 浏览器访问 http://localhost:8000

# 方式三：node
npx serve .
```

## 结果说明

- **加权正确率**：按难度加权后的总得分（非简单对错率）
- **知识星图**：18 轴雷达图，每轴一个领域；虚线点 = 该领域作答不足 50%，仅供参考
- **等级称号**：知识萌芽者 → 常识探索者 → 通识学习者 → 博学多识者 → 知识灯塔 → 知识全图持有者

## 数据与开发

- `data/taxonomy.md` — 领域分类设计文档（含跨域归属规则）
- `data/question-spec.md` — 出题规范
- `data/questions/*.js` — 题库（每领域一个文件）
- `scripts/validate.js` — 题库校验：`node scripts/validate.js`

## 隐私

所有答题数据仅保存在**你自己的浏览器 localStorage**，无任何网络请求，不上传任何数据。
