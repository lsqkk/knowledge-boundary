# 知识边界 · 题目生成规范（Question Spec）

> 所有出题子代理必须严格遵守本规范。目标：生成高质量、可区分知识深度的中文选择题。

## 1. 文件与数据格式

每个领域一个文件：`data/questions/<categoryId>.js`，内容为纯脚本（非 ES Module）：

```js
// <领域名> 题目
window.QUESTIONS_<CATEGORY_ID_UPPER> = [ ...题目数组... ];
```

每条题目对象结构（字段名固定，英文）：

```js
{
  id: "natural-001",            // 全局唯一 id：<categoryId>-<三位序号，从001起连续>
  category: "natural",           // 一级领域 id，必须与 js/domains.js 中的 id 完全一致
  subdomain: "物理学",            // 二级细分显示名，必须与 js/domains.js 该域 subdomains[].name 完全一致
  difficulty: "easy",            // 三选一："easy" | "medium" | "hard"
  question: "太阳系的中心天体是什么？",   // 题干，1~2 句
  options: ["太阳", "地球", "木星", "月球"],  // 恰好 4 个选项
  answer: 0,                     // 正确选项在 options 中的索引（0~3）
  explanation: "太阳是太阳系唯一的恒星，占太阳系总质量的 99.86%。" // 1~2 句解析
}
```

## 2. 数量与结构要求（必须逐条核对）

- 领域内**各二级细分的题数**必须严格等于 js/domains.js 中该域 subdomains 的 qty（已在上方注明的分配表里给出）。题数不可多不可少。
- 难度分布（整个领域）：**约 26% easy / 55% medium / 19% hard**（只允许 easy→medium 单向提升，不降级）。
- 同一细分内难度由浅入深：easy 测常识识别，medium 测一般理解，hard 测深度专精。
- id 从 001 连续编号，顺序建议按 subdomains 排列。

## 3. 选项质量（体现「知晓程度」的关键）

- **4 个选项都要是真实、合理、可被误选的内容**。错误选项应是真实存在且与主题相近、容易混淆的事物，而不是荒谬到靠常识就能排除的选项。
  - 例（坏）：问「太阳是恒星还是行星」时给「香蕉/石头」这种荒谬选项 —— 达不到区分知晓程度的目的。
  - 例（好）：问「世界上面积最大的国家」时给「俄罗斯 / 加拿大 / 中国 / 美国」四个真实大国。
- 干扰项与被测知识点处于同一「粒度」：比如问作品的作者，干扰项应是同时期/同类型的真实作者。
- **禁止**「以上都对 / 以上都不对 / 无法判断」式选项；**禁止**两个选项实质等同。
- 正确选项必须唯一且无歧义；若存在因表述含糊导致的争议，视为不合格。
- 选项长度自然起伏，不要刻意齐整到暴露答案，也不要全部等长。

## 4. 题目内容要求

- **事实必须准确、稳定、可核查**。不考仍在快速变动的最新新闻、未经定论的争议观点、主观审美判断。
- 面向中文母语、有一定通识的普通用户。语言简洁清晰，不堆砌术语；需要时可在题干给出必要背景。
- 不涉及政治敏感、宗教冒犯、暴力血腥等不适合的内容；历史题考公认史实。
- 同一细分内避免重复考查同一知识点；整个领域内题目间不要相互泄露答案。
- explanation 要真的「教人」：说清关键点，指出干扰项为何是错的（简短）。

## 5. 常见不合格情形（出题时自我检查）

- 某题不看选项仅凭题目就能推出答案（如直接问事实且唯一确定）→ 这是允许的（本身就在测该事实），但应保证这种题占比合理、且干扰项能诱骗记混的人。
- 硬题其实只是「冷门但简单」：应要求深度理解而非单纯冷门。
- 中西比例失衡（如全部考欧洲/全部考中国）。
- 选项中出现超纲生僻词却并非考点。

## 6. 交付前自检清单

- [ ] 题数 = 分配表总数；各细分 qty 匹配
- [ ] difficulty 分布 ≈ 40/40/20
- [ ] id 连续、唯一，category 与 subdomain 拼写与 domains.js 完全一致
- [ ] 每题恰好 4 个选项、answer 为有效索引
- [ ] 选项质量达标（真干扰项、无 absurd 选项、无「以上都对」）
- [ ] 事实经得起推敲（拿不准的宁可换题）
- [ ] 每个细分都有 explanation

用文本返回一句「已完成 N 题，通过自检」，并把写好的文件保存到指定路径。
